Le décor de base et le logotype typographique sont dessinés en XAML : aucune image de l’interface de duel n’est réutilisée.
Pour ajouter une illustration : placez une image background.png ici (portrait ou paysage, 1000 px minimum). Elle apparaît dans le panneau de gauche ; les textes et les cartes décoratives restent par-dessus.
Les couleurs, les ornements, le logo et les cartes vectorielles se modifient dans MainWindow.xaml et App.xaml.
